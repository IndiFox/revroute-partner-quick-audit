# Экспресс-аудит партнёрской программы

**Что мешает партнёру рекомендовать ваш продукт — и что улучшить первым?**

Открытый скилл RevRoute разбирает презентацию, условия или описание программы. Вы получаете шесть оценок с основаниями, до трёх ближайших действий и один заполненный материал: сообщение, карточку, вопросы квалификации или сценарий проверки демо.

## Попробовать

1. Скачайте [SKILL.md](SKILL.md) и прикрепите его к чату вместе с материалами своей программы. Можно загрузить несколько документов: презентацию, условия или договор, описание продукта, переписку и заметки со встреч. Достаточно и одного документа; лендинг необязателен.
2. Отправьте:

> Примени приложенный скилл к нашей партнёрской программе. Покажи, что уже помогает партнёру, что мешает следующему шагу и какое изменение сделать первым. Дай один заполненный материал, который можно использовать сейчас.

Обычный результат — 450–650 слов, даже если вводные объёмные; подробности можно запросить отдельно. Чтение PDF, сканов и страниц зависит от приложения; можно приложить извлечённый текст. Это разбор доступных материалов по шести рычагам, а не подтверждение фактической работы программы.

[Реалистичный пример: три источника → экспресс-аудит → готовый материал](examples/example.md). Внутри — развёрнутые учебные вводные и результат отдельного запуска скилла. Кейс адаптирован по мотивам практического разбора, с изменёнными деталями.

## Что проверяет скилл

| Рычаг | Что становится понятнее |
|---|---|
| Польза клиенту | Кому и когда рекомендовать продукт |
| Уверенность в качестве | На чём основано обещание результата |
| Социальная ценность | Почему партнёру удобно выступить с рекомендацией |
| Личная выгода | Что он получает относительно своих усилий |
| Защита репутации | Что будет при проблеме у приведённого клиента |
| Лёгкость действия | Можно ли сделать следующий шаг без лишней подготовки |

Скилл требует различать подтверждённый пробел и отсутствие данных, не переносить модельные расчёты в действующие условия, а предложения партнёру — в обещания его клиенту. Общий рейтинг и прогноз продаж не вычисляются.

## Установка как навыка

В приложении с поддержкой [Agent Skills](https://agentskills.io/specification) поместите этот репозиторий в папку навыков под именем `revroute-partner-quick-audit`.

Для проекта Codex:

```sh
git clone https://github.com/IndiFox/revroute-partner-quick-audit.git .agents/skills/revroute-partner-quick-audit
```

Начните новую сессию в проекте и вызовите `$revroute-partner-quick-audit`. [Официальная инструкция по каталогам навыков](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills). Для обычного чата установка не нужна: достаточно SKILL.md.

## Методика и границы

Основа — шесть рычагов из авторского вебинара Александра Марчука / RevRoute. Качественные статусы и формат короткого результата — адаптация для скилла; вебинарная формула не используется как калькулятор.

Версия **0.3.0, beta**. Скилл оценивает доступные материалы, а не подтверждает работу продукта, выплаты или рост продаж. Качество зависит от модели: [как проверяли и что пока не подтверждено](TESTING.md). Это самостоятельный первый шаг; для глубокой оценки нужны данные и отдельный разбор.
